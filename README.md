# Assistant Bot — персональний помічник у терміналі

Консольний застосунок-помічник для керування **адресною книгою** (контакти, телефони, email-и, адреси, дні народження) та **книгою нотаток**. Усі дані зберігаються локально у файлах `addressbook.pkl` і `notebook.pkl` за допомогою `pickle` і автоматично завантажуються при наступному запуску.

## Можливості

- Додавання, перейменування, видалення контактів
- Декілька телефонів, email-ів та адрес на один контакт
- Валідація формату телефону (10 цифр), email (`name@domain.com`), дати (`DD.MM.YYYY`)
- Перегляд контактів зі сторінковою навігацією у вигляді таблиці
- Пошук контактів за будь-яким полем (ім'я, телефон, email, адреса, день народження)
- Список днів народження на найближчі N днів із перенесенням з вихідних на понеділок
- Створення, редагування, видалення та пошук нотаток із автоматичним нумеруванням
- Підказка найближчої команди при помилковому вводі
- Автоматичне збереження даних при виході (включно з `Ctrl+C`, `Ctrl+Z`, `Ctrl+D`)

## Вимоги

- **Python 3.10 або новіший** (використовується синтаксис `match/case`)
- Стандартна бібліотека Python — зовнішні залежності не потрібні

Перевірити версію Python:

```powershell
python --version
```

## Встановлення

1. Клонуйте репозиторій або завантажте архів з проєктом:

   ```powershell
   git clone https://github.com/mireyyuriy/pycore-final-project-angry-birds.git
   cd pycore-final-project-angry-birds
   ```

2. (Необов'язково, але рекомендовано) Створіть та активуйте віртуальне середовище:

   **Windows (PowerShell):**
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   **macOS / Linux:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Жодних додаткових пакетів встановлювати не потрібно — застосунок використовує лише стандартну бібліотеку Python.

## Запуск

З кореня проєкту виконайте:

```powershell
python main.py
```

Після запуску ви побачите вітання, таблицю доступних команд та запрошення `Enter a command:`.

## Використання

### Загальні правила

- Команди вводяться у форматі `command arg1 arg2 ...` (аргументи розділені пробілами).
- Регістр команди не має значення (`Add-Contact` = `add-contact`).
- Пошук контакту за ім'ям **нечутливий до регістру** (`John` знайде `john`), але видалення/перейменування використовує точне ім'я з книги.
- Якщо команду введено неправильно — бот запропонує найближчі за написанням варіанти.
- При натисканні `Ctrl+C` / `Ctrl+Z` (Windows) / `Ctrl+D` (Unix) дані будуть збережені, після чого бот попрощається.

### Контакти

| Команда | Опис |
| --- | --- |
| `add-contact <name> <phone>` | Створити новий контакт або додати телефон існуючому |
| `rename-contact <old_name> <new_name>` | Перейменувати контакт |
| `remove-contact <name>` | Видалити контакт повністю |
| `show-contact <name>` | Показати всю інформацію по контакту у вигляді таблиці |

Приклад:

```
Enter a command: add-contact John 0501234567
Contact added.
Enter a command: rename-contact John John_Doe
Contact renamed to John_Doe.
```

### Телефони

| Команда | Опис |
| --- | --- |
| `add-contact <name> <phone>` | Додати ще один телефон до існуючого контакту |
| `change-phone <name> <old_phone> <new_phone>` | Замінити один із телефонів |
| `remove-phone <name> <phone>` | Видалити вказаний телефон |
| `show-phone <name>` | Показати всі телефони контакту |

> Телефон має містити **рівно 10 цифр без пробілів та символів** (приклад: `0501234567`).

### Дні народження

| Команда | Опис |
| --- | --- |
| `add-birthday <name> <DD.MM.YYYY>` | Встановити день народження |
| `show-birthday <name>` | Показати день народження контакту |
| `birthdays <days>` | Показати контакти, кого треба привітати протягом найближчих `<days>` днів |

> Якщо день народження припадає на суботу/неділю — дата привітання переноситься на понеділок.

Приклад:

```
Enter a command: add-birthday John_Doe 15.06.1990
Birthday added.
Enter a command: birthdays 30
John_Doe congratulation date: 15.06.2026
```

### Email-адреси

| Команда | Опис |
| --- | --- |
| `add-email <name> <email>` | Додати email до контакту (можна декілька) |
| `change-email <name> <old_email> <new_email>` | Замінити один із email-ів |
| `remove-email <name> <email>` | Видалити email |
| `show-emails <name>` | Показати всі email-и контакту |

> Email валідується за шаблоном `name@domain.com`.

### Поштові адреси

| Команда | Опис |
| --- | --- |
| `add-address <name> <address text>` | Додати адресу (текст може містити пробіли) |
| `remove-address <name> <address text>` | Видалити вказану адресу |
| `show-address <name>` | Показати всі адреси контакту |

Приклад:

```
Enter a command: add-address John_Doe Kyiv, Khreshchatyk 1
Address added.
```

### Пошук та перегляд

| Команда | Опис |
| --- | --- |
| `all-contacts <page_size>` | Показати всі контакти посторінково (за замовчуванням 5 на сторінці) |
| `search-contacts <query>` | Знайти контакти за частковим збігом у будь-якому полі |

Під час посторінкового перегляду натисніть `Enter` для наступної сторінки або введіть `q` для виходу.

### Нотатки

| Команда | Опис |
| --- | --- |
| `add-note <text>` | Створити нотатку (ID присвоюється автоматично) |
| `edit-note <id> <new text>` | Замінити текст нотатки |
| `remove-note <id>` | Видалити нотатку (інші нотатки перенумеровуються від 1) |
| `show-note <id>` | Показати одну нотатку |
| `search-notes <query>` | Знайти нотатки за частковим збігом у тексті |
| `all-notes <page_size>` | Показати всі нотатки посторінково (за замовчуванням 5) |

Приклад:

```
Enter a command: add-note Buy bread and milk
Note added with id 1.
Enter a command: edit-note 1 Buy bread, milk and eggs
Note #1 updated.
```

### Системні команди

| Команда | Опис |
| --- | --- |
| `hello` | Привітання |
| `help` | Показати таблицю всіх команд |
| `close` або `exit` | Зберегти дані та завершити роботу |

## Формати та обмеження

- **Ім'я контакту** — будь-який непорожній рядок без пробілів усередині (інакше частина потрапить до інших аргументів).
- **Телефон** — рівно 10 цифр (`isdigit`), наприклад `0501234567`.
- **Email** — має містити `@` та крапку, без пробілів (`john@example.com`).
- **День народження** — формат `DD.MM.YYYY` (`15.06.1990`).
- **Адреса** і **текст нотатки** — довільний рядок (усі аргументи після команди/імені об'єднуються пробілами).

## Зберігання даних

- Адресна книга зберігається у файлі **`addressbook.pkl`**.
- Нотатки зберігаються у файлі **`notebook.pkl`**.
- Обидва файли створюються автоматично у поточній робочій директорії під час першого виходу із застосунку.
- Дані зберігаються при будь-якому коректному виході: командою `exit`/`close`, `Ctrl+C`, `Ctrl+Z` (Windows) або `Ctrl+D` (Unix).
- Щоб скинути дані, видаліть відповідний `.pkl`-файл — наступний запуск створить порожню книгу.

## Структура проєкту

```
pycore-final-project-angry-birds/
├── main.py          # Точка входу, цикл REPL, збереження/завантаження даних
├── cli.py           # Парсинг команд, довідка, підказка найближчої команди
├── handlers.py      # Обробники всіх команд (контакти, нотатки, ДН тощо)
├── models.py        # AddressBook, NotesBook, Record, Note
├── fields.py        # Field, Name, Phone, Email, Address, Birthday + валідація
├── rendering.py     # Рендеринг таблиць контактів і нотаток
├── errors.py        # Декоратор input_error і кастомні винятки
├── addressbook.pkl  # (створюється автоматично) збережені контакти
└── notebook.pkl     # (створюється автоматично) збережені нотатки
```
